# 5. Оформление сайта: CSS и разные размеры экрана

## Что меняют в CSS

**CSS** — правила внешнего вида страницы. С их помощью задают цвета, шрифты, размеры, отступы и расположение блоков. Здесь же описаны анимации и изменения для телефона.

Если нужно исправить надпись или цену товара, CSS не понадобится. Если нужно поменять цвет кнопки, расстояние между блоками или ширину карточки — искать нужно здесь.

Пример правила:

```css
.btn-primary {
  background: var(--primary);
  border-radius: 999px;
}
```

Оно задаёт главным кнопкам цвет из общей настройки `--primary` и сильно скруглённые края. Класс `.btn-primary` — имя группы элементов, к которой применяется правило.

## Где искать оформление

Все пути ниже находятся внутри `frontend/css/`.

| Путь | Назначение |
|---|---|
| `main.css` | Подключает оформление покупательской части в нужном порядке |
| `admin.css` | Подключает общие стили и оформление админ-панели |
| `base/variables.css` | Общие цвета, шрифты, тени, скругления и размеры |
| `base/base.css` | Базовый вид текста, страницы и контейнера |
| `base/interaction.css` | Выделение, прокрутка и отклик на нажатия |
| `components/` | Общие кнопки, шапка, карточки, окна, уведомления |
| `pages/` | Особенности конкретных страниц |
| `admin/` | Меню, таблицы и формы управления магазином |
| `responsive/` | Основные правила для разных экранов и уменьшения движения |

Чтобы поправить каталог на телефоне, сначала смотрите `responsive/phone/catalog.css`. Чтобы изменить каталог на всех экранах, начинайте с `pages/catalog.css`. Чтобы изменить общий цвет кнопок, начинайте с `base/variables.css`.

## Общие настройки внешнего вида

Повторяющиеся значения собраны в CSS-переменные. Их также называют **дизайн-токенами**: это именованные настройки, которые используют разные части сайта.

| Имя | Что задаёт |
|---|---|
| `--bg` | Основной кремовый фон `#f3efe6` |
| `--surface` | Светлый фон карточек `#faf8f3` |
| `--primary` | Основной зелёный цвет `#1f3a2d` |
| `--text`, `--text-muted` | Обычный и второстепенный текст |
| `--danger`, `--gold`, `--sage` | Ошибки, золотистые и светло-зелёные акценты |
| `--font-serif` | Шрифт заголовков Cormorant Garamond |
| `--font-sans` | Шрифт основного текста Manrope |
| `--font-hand` | Рукописный шрифт Caveat |
| `--container` | Максимальная ширина основного содержимого |
| `--radius`, `--shadow` | Скругления и тени |

Шрифты загружаются с Google Fonts. Если загрузка недоступна, браузер использует запасные шрифты из списка.

## Как сайт подстраивается под экран

**Адаптивность** означает, что блоки перестраиваются под доступную ширину. На телефоне меню превращается в кнопку, фильтры каталога открываются панелью, а некоторые строки таблиц становятся карточками.

CSS считает ширину в пикселях браузера. Она зависит и от размера окна, и от масштаба системы. Надпись «4K» на мониторе сама по себе не определяет, какое правило сработает.

| Размер или условие | Где искать правила |
|---|---|
| Ноутбук; в том числе ширина 1025–1365 пикселей | `responsive/desktop/laptop.css` |
| Широкие экраны: от 1440 пикселей | `responsive/desktop/large-screens.css` |
| Планшет: до 1024 пикселей | `responsive/tablet/` |
| Телефон: до 760 пикселей, дополнительные меньшие пороги | `responsive/phone/` |
| Низкий экран в горизонтальном положении | `responsive/phone/landscape.css` |
| Сенсорный экран | `responsive/touch/touch.css` |
| Системная настройка «Уменьшить движение» | `responsive/accessibility/reduced-motion.css` |
| Админ-панель на небольшом экране | `responsive/admin/` |

На широких экранах содержимое расширяется от базовых 1280 до 1640 пикселей. С ширины 1800 пикселей постепенно растёт масштаб интерфейса через переменную `--zoom`: например, 1,12 при 1800, 1,35 при 2200 и 2 при 3400. Все пороги и дополнительные ступени находятся в `large-screens.css`.

Для телефонов предусмотрены увеличенные зоны нажатия, учёт вырезов экрана и полей, которые не должны вызывать автоматическое приближение при вводе. Это правила реализации; после правок удобство всё равно нужно проверять в браузере и на устройстве.

## Анимации

В проекте есть плавное появление блоков, раскрытие фотографий, карусели, второе фото товара при наведении, добавление в корзину и эффекты на странице тестовой оплаты.

Основные файлы: `components/motion.css`, `components/transitions.css` и `frontend/js/components/reveal.js`. Первый экран главной появляется с анимацией, затем остаётся неподвижным. Поддержка отдельных переходов зависит от браузера. При системной настройке «Уменьшить движение» эффекты ограничиваются.

## Как проверить правку

1. Откройте сайт через локальный сервер из раздела 2.
2. Проверьте обычное окно компьютера.
3. В Chrome или Edge нажмите F12, затем Ctrl + Shift + M, чтобы включить режим устройств.
4. Проверьте ширины около 360, 390, 768, 1024, 1280 и 1920 пикселей; телефон также поверните горизонтально.
5. Убедитесь, что текст читается, кнопки доступны, блоки не накладываются и не появилась ненужная горизонтальная прокрутка.

Это ручная проверка. Автоматические проверки кода не доказывают, что страница хорошо выглядит на всех размерах.

## Технические подробности: порядок правил и публикация

Если несколько правил меняют одно свойство, результат зависит от приоритета селектора, `!important` и порядка подключения. При равном приоритете действует более позднее правило. Адаптация подключается после основных правил, чтобы уточнять их для нужного экрана.

При публикации `deploy/prepare_frontend.py` объединяет исходные CSS-файлы в `.public/css/main.css` и `.public/css/admin.css`, поправляя пути к изображениям. Это уменьшает число запросов к файлам. Править нужно исходники в `frontend/css/`, потому что следующая сборка заменит результат в `.public/`.
