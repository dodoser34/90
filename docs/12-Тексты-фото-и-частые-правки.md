# 12. Тексты, фото и частые правки

Сначала определите, что хотите изменить. Товар, цену, остаток, категорию или фото блока «Жизнь магазина» можно поменять в браузере через админ-панель. Порядок — [глава 11](11-Админ-панель.md). Надписи сайта, контакты и оформление находятся в файлах проекта.

Читать это руководство можно в Word или другом приложении для документов. Редактор кода нужен только тому, кто меняет исходные файлы сайта. Для этого подойдёт любой редактор обычного текста с поддержкой UTF-8; Visual Studio Code — один из вариантов. Word не подходит для сохранения файлов `.js`, `.css` и `.html`.

## Заменить надпись

**Зачем:** обновить текст страницы, кнопки или сообщения.

1. Сделайте копию нужного файла в отдельной папке за пределами публикуемого сайта.
2. Откройте файл из таблицы ниже в текстовом редакторе. Все эти файлы лежат в `frontend/texts/ru/`.
3. Найдите старую фразу через поиск редактора, обычно `Ctrl + F`.
4. Меняйте текст между кавычками. Сами кавычки, запятые, скобки и имена полей оставьте на месте. Внутри строки с одинарными кавычками не добавляйте неэкранированный знак `'`.
5. Сохраните файл в UTF-8, обновите локальную страницу через `Ctrl + F5` и проверьте результат.
6. Для рабочего сайта передайте изменение на сервер и пересоберите публичные файлы по [главе 13](13-Публикация-на-сервере.md). Сохранения на своём компьютере недостаточно.

**Результат:** новая надпись видна в нужном месте, страница продолжает открываться. Если страница перестала работать, верните копию файла и проверьте кавычки и знаки рядом с изменением.

| Файл в `frontend/texts/ru/` | Что меняется |
|---|---|
| `common.js` | Меню, подвал, общие кнопки, статусы и уведомления |
| `home.js` | Главная страница |
| `catalog.js` | Каталог и фильтры |
| `product.js` | Общие подписи страницы товара и отзывов |
| `about.js` | «О нас», цифры, подписи шести фото, контактный блок |
| `delivery.js` | Условия доставки, таблица сроков, вопросы и ответы |
| `cart.js`, `checkout.js`, `pay.js` | Корзина, оформление и оплата |
| `login.js`, `account.js` | Вход, регистрация и личный кабинет |
| `favorites.js`, `not-found.js` | Избранное и страница отсутствующего адреса |

В строках есть служебные вставки. `<br>` задаёт перенос строки. Вместо `{count}`, `{name}`, `{sum}` сайт подставляет число, имя или сумму. Запись `{count|товар|товара|товаров}` выбирает правильное окончание. Эти части не удаляйте и не переводите.

Например, строка таблицы доставки содержит три значения: место или способ, срок, стоимость:

```js
['Костанай — курьер', '1 день', '1 000 ₸'],
```

Один вопрос и ответ содержат два значения:

```js
['Как отследить заказ?', 'После отправки сообщим трек-номер.'],
```

## Изменить контакты и стоимость доставки

**Откройте:** `frontend/js/config.js`.

| Поле | Что указать |
|---|---|
| `shopName` | Название магазина |
| `tagline` | Короткое описание магазина |
| `email` | Почту для связи с покупателями |
| `address` | Адрес магазина; пустое значение скрывает адресный блок |
| `mapUrl` | Ссылку «Поделиться» из сервиса карт |
| `freeShippingFrom` | Сумму бесплатной курьерской доставки, числом без пробелов |
| `courierPrice` | Стоимость курьерской доставки, числом без пробелов |
| `adminEmails` | Почты администраторов только для режима без API; к рабочим серверным правам не относится |

1. Найдите нужное поле и замените его значение.
2. Если меняете доставку рабочего магазина, согласованно измените `FREE_SHIPPING_FROM` и `COURIER_PRICE` в `deploy/.env` на сервере. Итоговую стоимость заказа рассчитывает API по своим настройкам.
3. Обновите видимые тексты условий в `delivery.js`, если в них указаны старые суммы.
4. Опубликуйте изменения; после изменения `.env` пересоздайте API командой из главы 13.
5. Проверьте подвал, страницу доставки и итог нового заказа.

Контактная почта в `config.js` и почта отправителя писем в настройках SMTP — разные параметры.

## Заменить фотографии оформления

**Зачем:** обновить фото главной, «О нас» или других страниц. Фото товаров загружаются через админ-панель.

1. Подготовьте изображение подходящего размера и пропорций.
2. Сохраните резервную копию старого файла вне публичных папок.
3. Замените файл с тем же именем и расширением в `frontend/assets/images/`.
4. Пересоберите и опубликуйте сайт. Проверьте изображение на компьютере и телефоне: важный предмет не должен обрезаться.

| Место | Путь внутри `frontend/assets/images/` |
|---|---|
| Главный экран | `pages/home/hero-background.jpg` и `pages/home/hero-products.webp` |
| Блок категорий | `pages/home/categories-bg.jpg` |
| Фото магазина | `pages/about/about-shop.jpg` |
| Шесть фото «Жизнь магазина» | `pages/about/gallery-1.jpg` … `gallery-6.jpg`; проще менять в админ-панели |
| Доставка | `pages/delivery/delivery-side.jpg` |
| Вход | `pages/login/auth-side.jpg` |
| Картинка при отправке ссылки | `common/og-image.jpg` |
| Декоративные веточки | `decor/*.png` с прозрачным фоном |

Смена расширения в имени не преобразует картинку. Например, JPG не станет WEBP от переименования. Подробные требования к изображениям — [отдельный файл](Требования-к-фотографиям.md).

## Изменить цвета, шрифты и логотип

Основные цвета находятся в `frontend/css/base/variables.css`:

```css
--bg: #F3EFE6;
--primary: #1F3A2D;
--text: #22251F;
```

`--bg` — фон, `--primary` — основной зелёный цвет, `--text` — текст. Измените код цвета, сохраните и проверьте читаемость текста и кнопок после публикации.

Заголовки используют Cormorant Garamond, основной текст — Manrope, рукописные фразы — Caveat. Для смены шрифта нужно согласованно обновить подключения HTML и CSS. Логотип в формате SVG создаётся кодом в `frontend/js/core/icons.js`. Эти изменения удобнее передать разработчику.

Название в `shopName` меняет видимые элементы интерфейса. Названия вкладок браузера дополнительно задаются в полях `meta` файлов текстов.

## После публикации всё ещё старая версия

Сначала выполните полное обновление страницы. Если браузер продолжает брать старые файлы, разработчику нужно согласованно изменить `VERSION` в `frontend/js/app.js` и номера `?v=` в подключениях HTML. В исходной версии используется `23`: при следующем обновлении выбирайте новый общий номер. Не заменяйте все числа `23` по проекту: менять нужно только номера версии ресурсов. Затем заново соберите `.public/`.

Скорость автолистания каруселей задаёт `INTERVAL` в `frontend/js/components/carousel.js` в миллисекундах. Длительности переходов находятся в `frontend/css/components/transitions.css`, других анимаций — в `frontend/css/components/motion.css`. После изменений проверяйте, что интерфейс остаётся удобным на телефоне.
