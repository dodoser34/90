# 5. Фронтенд: CSS — оформление, анимации, адаптивность

## Что такое CSS

**CSS** — язык оформления: цвета, шрифты, отступы, расположение блоков, анимации.
HTML отвечает «что на странице», CSS — «как это выглядит». Правило CSS выглядит так:

```css
.btn-primary { background: var(--primary); border-radius: 999px; }
```
— «у всех главных кнопок фон фирменного зелёного цвета и полностью скруглённые края».

## Как разложены стили — `frontend/css/`

```
css/
├─ main.css            главный файл: подключает остальные по порядку (база → компоненты → страницы → декор → адаптация)
├─ admin.css           стили админки: подключает main.css + части админки
├─ base/
│  ├─ variables.css    ДИЗАЙН-ТОКЕНЫ: цвета, шрифты, радиусы, тени, ширина страницы — меняются здесь для всего сайта
│  ├─ base.css         сброс стилей браузера, типографика, контейнер, иконки
│  └─ interaction.css  полосы прокрутки, выделение текста, отклик на нажатие
├─ components/         повторяющиеся элементы: кнопки, шапка, подвал, карточка товара, карусель, формы,
│                      окна, уведомления, «пусто», хлебные крошки, украшения-веточки, анимации (motion.css),
│                      переходы между страницами (transitions.css)
├─ pages/              по файлу на страницу: home, catalog, product, product-reviews, about, delivery,
│                      cart-checkout, pay, login, account, not-found
├─ admin/              части админки: каркас и меню, обзор, таблицы, форма товара, категории, заказы, фото «О нас»
└─ responsive/         ВСЯ адаптация под размеры экрана (см. ниже)
```

**Порядок важен:** при одинаковой специфичности и приоритете более позднее правило перекрывает раннее. Также учитываются селекторы и `!important`. Адаптация подключается последней, чтобы уточнять основные правила.

## Дизайн-токены (`base/variables.css`)

| Токен | Значение | Где используется |
|---|---|---|
| `--bg` | `#F3EFE6` кремовый | фон страницы |
| `--surface` | `#FAF8F3` | карточки, панели |
| `--primary` | `#1F3A2D` лесной зелёный | кнопки, акценты, логотип |
| `--text` / `--text-muted` | `#22251F` / `#5F5F55` | основной и второстепенный текст (контраст ≥ 5:1) |
| `--sage`, `--gold`, `--danger` | шалфей, золото, кирпичный | метки, звёзды, ошибки |
| `--font-serif` | Cormorant Garamond | заголовки |
| `--font-sans` | Manrope | обычный текст |
| `--font-hand` | Caveat | рукописные фразы |
| `--container` | 1280–1640 px | ширина содержимого (растёт на больших экранах) |
| `--radius`, `--shadow` | скругления и тени | карточки, кнопки |

Все три шрифта поддерживают кириллицу и подключаются с Google Fonts.

## Анимации (`components/motion.css`, `components/transitions.css`, `js/components/reveal.js`)

| Эффект | Где |
|---|---|
| Блоки плавно поднимаются при прокрутке, по очереди | все страницы |
| **Фото раскрываются «шторкой» снизу вверх**, изображение внутри мягко уменьшается | «О нас» (мозаика, фото миссии), «Доставка» |
| **Появление первого экрана:** фон проявляется из лёгкой размытости, косметика мягко поднимается, текст появляется по строкам; потом всё неподвижно | главная |
| Второе фото товара при наведении | карточки товаров |
| Подпись выезжает при наведении на фото | мозаика «Жизнь магазина» |
| Плавные переходы между страницами, фото товара «перелетает» на страницу товара | Chrome, Edge, Safari 18+ |
| Миниатюра «улетает» в корзину, сердечко «подпрыгивает» | карточки товаров |
| Веточки-украшения слегка покачиваются | края страниц |
| Живая банковская карта, сканирующая линия QR | страница оплаты |

Блоки, видимые сразу при открытии страницы, не анимируются — ничего не «мигает».
Если в системе включено **«Уменьшить движение»**, анимации отключаются. Эффекты наведения работают только с мышью,
чтобы на телефоне карточка не «залипала» после касания.

## Адаптивность: телефон, планшет, ноутбук, 2K, 4K

**Вся адаптация лежит в одной папке `css/responsive/`.** Там правила вида «если экран уже N пикселей — делай так» (*media queries*).

```
responsive/
├─ index.css               порядок подключения
├─ desktop/large-screens.css   Full HD, 2K, 4K, 5K, 8K: ширина содержимого и увеличение интерфейса
├─ desktop/laptop.css      ноутбуки 1025–1365 px и правила «только для компьютера»
├─ tablet/<раздел>.css     планшеты до 1024 px
├─ phone/<раздел>.css      телефоны до 760 px (ступени 600, 560, 480, 400, 360 px)
├─ phone/landscape.css     телефон горизонтально (низкий экран)
├─ touch/touch.css         сенсорные экраны: зоны нажатия, поля без автоприближения, вырез экрана
├─ accessibility/reduced-motion.css   «уменьшить движение»
└─ admin/                  админка на планшете и телефоне
```

Разделы в `tablet/` и `phone/` во многом повторяются, но `footer.css` есть только в `phone/`. Основные имена: `base`, `header`, `footer`, `product-card`, `home`, `catalog`, `product`, `about`,
`delivery`, `cart-checkout`, `account`, `login`. Хотите поправить, как каталог выглядит на телефоне, — откройте `phone/catalog.css`.

| Устройство | Ширина | Что происходит |
|---|---|---|
| Маленький телефон | 320–360 px | Поля по краям 16 px, каталог в 2 колонки, кнопки на всю ширину, фото товара листается пальцем |
| Телефон | 375–560 px | Меню в «бургере» ≡, поиск по иконке лупы, «липкая» кнопка «В корзину», таблицы превращаются в карточки, мозаика «О нас» в 2 колонки |
| Большой телефон | 561–760 px | Блоки преимуществ и ценностей столбиком |
| Телефон горизонтально | высота до 520 px | Низкая шапка, текст и фото рядом |
| Планшет | 761–1024 px | Каталог в 3 колонки, фильтры в выезжающей панели, мозаика в 3 колонки |
| Ноутбук | 1025–1439 px | Полное меню, фильтры слева, содержимое до 1280 px |
| Монитор | 1440–1599 px | Содержимое до 1400 px |
| Широкий монитор | от 1600 px | Содержимое до 1520 px, **4 товара в ряд в каталоге и 5 в каруселях** — по бокам аккуратные поля, а не пустые полосы |
| Full HD 1920 / 2K / 4K | от 1800 / 2200 / 3400 px | Интерфейс пропорционально увеличен в 1,12 / 1,35 / 2 раза, содержимое до 1640 px |

**Зачем увеличивать интерфейс на 2K и 4K:** иначе на мониторе 3840 px сайт выглядит маленькой полоской с мелким текстом.
Свойство `zoom` пропорционально увеличивает всё — пропорции дизайна сохраняются. Числа — в `responsive/desktop/large-screens.css`.

Ещё учтено:
- кнопки удобного для пальца размера, у мелких элементов (точки галереи) увеличена невидимая зона нажатия;
- поля ввода на iPhone — шрифт 16 px, страница не приближается сама;
- iPhone с «чёлкой»: меню и кнопки не заходят под вырез и системную полоску;
- высота меню и окон считается по видимой части экрана (адресная строка на телефоне то появляется, то прячется).

**Как проверить самому:** Chrome → `F12` → значок телефона (`Ctrl + Shift + M`) → выберите устройство или введите ширину.

**Матрица для ручной проверки:** телефоны 320×568, 360×740, 375×667, 390×844, 430×932 и горизонтальная ориентация; планшеты 768×1024, 820×1180, 1024×768; компьютеры 1280×720–3840×2160. Проверяйте горизонтальную прокрутку, наложения, читаемость и доступность кнопок. Текущие Node-тесты не подтверждают отображение на этих размерах.

## Как стили попадают на сервер

В исходниках стили разложены по ~60 файлам — так их удобно править. При публикации скрипт `deploy/prepare_frontend.py`
**склеивает их в один файл** `css/main.css` (и `css/admin.css`) и пересчитывает пути к картинкам. Браузер скачивает один файл вместо 60 —
снижается число запросов за CSS. Фактическую скорость и совпадение отображения после изменений проверяют отдельно в браузере; гарантированного коэффициента ускорения нет.
