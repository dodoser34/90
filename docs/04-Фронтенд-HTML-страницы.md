# 4. Фронтенд: HTML и страницы сайта

## Что такое HTML и как здесь устроена страница

**HTML** — язык разметки: из него состоит «каркас» страницы (заголовки, абзацы, кнопки, картинки).
Браузер читает HTML-файл и рисует страницу; внешний вид задаёт CSS ([раздел 5](05-Фронтенд-CSS-оформление-и-адаптивность.md)),
поведение — JavaScript ([раздел 6](06-Фронтенд-JavaScript.md)).

В этом проекте HTML-файлы — **короткие каркасы без текста**. Каждый файл содержит:

1. `<head>` — служебная часть:
   - политика безопасности (`Content-Security-Policy`: скрипты можно загружать только с этого сайта — [раздел 9](09-Безопасность.md));
   - значок вкладки `favicon.svg`, шрифты Google Fonts, файл стилей `css/main.css`;
   - **одна строка подключения скриптов**: `<script src="js/app.js" data-page="catalog">` — загрузчик сам подключит всё нужное этой странице.
2. `<body data-page="…">` — каркас: место под шапку (`#site-header`), основное содержимое и подвал (`#site-footer`).
   Шапку, подвал и большую часть содержимого рисует JavaScript.
3. Тексты подставляются по меткам: `<h1 data-t="about.title"></h1>` — сюда вставится текст из `texts/ru/about.js`.

Почему так: одна правка шапки или текста сразу меняется на всех страницах, а HTML-файлы остаются простыми.

Основы тегов, атрибутов, DOM и путей с примерами — [19](19-Основы-HTML-CSS-JS-Python.md).

## Шапка и подвал (на всех страницах)

- **Шапка:** логотип, меню, выпадающий «Каталог» с подкатегориями, поиск, избранное, профиль/вход, корзина со счётчиками.
  Поиск подсказывает товары после 2 букв (название, бренд, теги, назначение); по подсказкам можно ходить стрелками.
  На экранах уже 1024 px меню прячется в кнопку ≡ (закрывается крестиком, Esc или свайпом).
- **Подвал:** три преимущества, ссылки по разделам, контакты, копирайт.

## Главная — `index.html`

- Первый экран: заголовок, кнопка в каталог, три преимущества на полупрозрачных подложках.
  Фото собрано из двух слоёв (фон и косметика) с анимацией первого появления; постоянного параллакса за мышью в текущем `home.js` нет. Если слои не загрузились, используется резервное `hero.jpg`.
- Карусели «Популярные товары» и «Новинки» с автопрокруткой (на широких экранах — по 5 карточек).
- Баннер с кругами категорий.
- «Популярное» берёт товары с метками «Хит» или «Популярное», а если таких нет — доступный список каталога. «Новинки» сначала берут товары с меткой «Новинка», затем дополняются остальными по дате.

## Каталог — `pages/catalog.html`

- Дерево категорий, «Новинки», «Скидки»; фильтры **«Для чего»** и **«Бренд»** с количеством товаров.
- Сортировка (популярные, цена, новинки, рейтинг), фильтр цены с ползунком, вид «крупно / сетка / список».
- По 12 товаров на странице, «Показать ещё», номера страниц.
- **Все фильтры записываются в адрес страницы** (`catalog.html?cat=herbs&purpose=…`) — ссылкой можно поделиться.
- При наведении мыши на карточку показывается второе фото товара, если оно есть.
- На телефоне и планшете фильтры открываются отдельной панелью.

## Товар — `pages/product.html?slug=…`

- Галерея с просмотром на весь экран (на телефоне — листание пальцем и точки под фото).
- Название, рейтинг, цена, «Для чего», теги, количество, «В корзину», избранное, остаток.
- Вкладки: **Описание**, **Состав**, **Применение** (с мерами предосторожности), **Характеристики**, свои разделы владельца, **Отзывы**.
- Справа — «Кому подходит», ниже — похожие товары.
- **Отзывы:** сводка (средняя оценка, % рекомендаций, распределение по звёздам), сортировка, «Полезно», ответы магазина, «Покупка подтверждена».
  «Оставить отзыв» доступно после входа; гостя отправит на вход и вернёт к отзывам.

## О нас — `pages/about.html`

- Фото магазина и миссия, ценности, «досчитывающиеся» цифры, «Почему нам доверяют».
- **«Жизнь магазина»** — мозаика из 6 фото разного размера: при прокрутке фото «раскрываются», при наведении появляется подпись,
  по нажатию — просмотр на весь экран. Фото заменяются в админке.
- Контакты.

## Доставка и оплата — `pages/delivery.html`

Способы доставки и оплаты, таблица сроков и стоимости, частые вопросы, «Остались вопросы?». Все тексты — `texts/ru/delivery.js`.

## Корзина — `pages/cart.html`

Товары, количество (не больше остатка), удаление, итог, полоса «до бесплатной доставки».
Закончившиеся или скрытые товары помечаются и в заказ не попадают. Корзина работает без входа.

## Оформление заказа — `pages/checkout.html`

Три шага: контакты, доставка (курьер / по Казахстану / самовывоз), оплата.
Способы оплаты приходят с сервера: перевод на Kaspi, наличные, тестовая оплата картой и Kaspi ([раздел 10](10-Оплата.md)).
Телефон форматируется сам; номер без кода страны (`701 123 45 67`) дополняется до `+7 (701) 123-45-67`.
После заказа — номер (№1001, №1002…) и инструкция по оплате.

## Оплата заказа — `pages/pay.html?order=…`

Страница тестовой оплаты:
- **картой** — «живая» карта повторяет вводимые цифры и переворачивается при вводе CVC; подсказки с тестовыми картами;
- **через Kaspi** — QR-код со сканирующей линией и имитация экрана приложения с кнопкой «Подтвердить оплату».

Деньги не списываются; сервер проверяет данные и отмечает заказ «Оплачен».

## Вход и регистрация — `pages/login.html`

- **Вход** — почта и пароль, «Забыли пароль?» (код из письма → новый пароль).
- **Регистрация** — имя, почта, пароль (от 8 символов), повтор пароля; затем подтверждение почты 6-значным кодом.
- Вкладки «Вход ⇄ Регистрация» переключаются плавно, без перезагрузки.
- В демо-версии под формой — «Быстрый вход» в демо-аккаунты.

## Личный кабинет — `pages/account.html`

| Раздел | Что внутри |
|---|---|
| Мои заказы | Номер, статус, доставка, оплата и кнопка «Перейти к оплате» для неоплаченных тестовых заказов, «Оценить» у полученных товаров, «Повторить заказ» |
| Мои отзывы | Свои отзывы со статусом и ответами магазина, «Изменить» |
| Профиль | Имя, почта, телефон |
| Пароль | Смена пароля; удаление аккаунта |

## Избранное — `pages/favorites.html`

Товары, отмеченные сердечком. Работает без входа; скрытые товары не показываются.

## Страница 404 — `404.html`

Показывается для неверного адреса. Небольшой встроенный скрипт выставляет «корень» сайта, чтобы стили нашлись даже по адресу вида `/a/b/c`.
Этот скрипт разрешён политикой безопасности по его отпечатку (хешу) — если его поменять, хеш нужно пересчитать ([раздел 9](09-Безопасность.md)).
