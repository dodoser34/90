# Руководство по магазину K Beauty C Health

Это инструкция к интернет-магазину корейской косметики и трав. Она поможет посмотреть сайт, управлять товарами и заказами, найти нужный файл и понять, как работает проект. Начальные знания программирования не нужны. Технические разделы можно читать позже, когда понадобится что-то изменить.

## Как читать без VS Code

Откройте файл [Руководство по магазину.docx](Руководство%20по%20магазину.docx) в Microsoft Word на компьютере или телефоне. Для чтения документа не нужно запускать сайт, устанавливать Python или открывать редактор кода. На телефоне в Word удобно включить мобильный вид, если такая кнопка есть в вашей версии приложения.

Есть и [версия для браузера](Читать-в-браузере.html). Это один файл: его можно сохранить и открыть без интернета. Текст подстраивается под ширину экрана, а оглавление ведёт к нужной главе. Интернет понадобится, только если вы перейдёте на внешний сайт.

В Word названия глав в оглавлении работают как ссылки. На компьютере Word может требовать удерживать Ctrl при нажатии. На телефоне нажмите ссылку и выберите переход, если приложение предложит. Главы также можно искать через поиск по документу.

## С чего начать

- **Хочу просто посмотреть магазин.** Прочитайте главу 1, затем в главе 2 выберите демо. Публиковать сайт в интернете для этого не нужно.
- **Хочу управлять магазином.** Начните с главы 11. Для замены надписей и фотографий нужна глава 12.
- **Хочу понять код с нуля.** Прочитайте главы 1, 19 и 3. Затем переходите к главам 4–8.
- **Хочу коротко разобраться в устройстве магазина.** Откройте главу 17. В ней короткие объяснения устройства магазина.
- **Хочу запустить настоящий магазин в интернете.** Прочитайте главы 10, 13 и 14. Настройки и дальнейшее обслуживание описаны в главах 23 и 25.
- **Хочу продолжить разработку.** Используйте главы 20–27 как справочник. Читать их подряд необязательно.

## Что важно понять до запуска

**Демо** — версия для знакомства с сайтом. Она содержит примеры товаров и хранит изменения в вашем браузере. Другой человек не увидит ваши заказы и изменения.

**Магазин с сервером** хранит товары, пользователей и заказы в общей базе. Именно такой режим нужен для работы с настоящими покупателями. Запуск сервера на своём компьютере ещё не делает сайт доступным в интернете.

**Тестовая оплата** только показывает, как проходит платёж. Она не списывает деньги. Настоящее подключение платёжного сервиса требует отдельной настройки и проверки.

Адрес **localhost** означает «этот компьютер». Если открыть такой адрес на телефоне, он будет указывать на сам телефон. Он не откроет магазин, запущенный на вашем ПК. Это ограничение запуска сайта; читать руководство на телефоне можно независимо от него.

## Как понимать пути и команды

**Корень проекта** — главная папка, в которой лежат README.md и папки frontend, backend, deploy и docs. Если написано `frontend/js/config.js`, сначала откройте frontend, затем js, затем файл config.js.

**Терминал** — окно для ввода команд. В Windows можно открыть папку проекта в Проводнике, нажать адресную строку, ввести `powershell` и нажать Enter. Команды вводят в открывшемся окне. Для чтения документа терминал не нужен.

Строку из блока с командой копируйте целиком и нажимайте Enter. Если в блоке несколько строк, выполняйте их по очереди. Слова перед блоком объясняют, на каком компьютере и из какой папки запускать команду. Команды для Linux-сервера не нужно вводить в обычный PowerShell на своём ПК.

Команда `cd backend` означает «перейти в папку backend». Команда `cd ..` возвращает на одну папку выше. Сочетание Ctrl + C останавливает работающий сервер в том окне, где он запущен.

Если пример содержит `example.kz` или подпись «ваш домен», подставьте настоящий адрес своего сайта. Если написано «ваш пароль», задайте свой пароль. Не заменяйте имена параметров и команд произвольно.
