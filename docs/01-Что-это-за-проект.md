# 1. Что это за проект

## Главное за одну минуту

**K-Beauty | C-Health** — сайт магазина корейской косметики и натуральных трав для покупателей в Казахстане.

Покупатель находит товар, добавляет его в корзину и оформляет заказ. Владелец видит заказ в специальном разделе управления магазином — **админ-панели**. Там же он меняет товары, остатки, фотографии и статусы заказов.

Проект можно открыть на своём компьютере для знакомства. Для работы с настоящими покупателями его нужно отдельно разместить в интернете и настроить. Инструкции по этим двум задачам различаются.

## Что может покупатель

- Смотреть каталог, искать товары, выбирать категорию, бренд, назначение и цену.
- Открывать карточку товара: фотографии, описание, состав, применение, характеристики и отзывы.
- Сохранять избранное и собирать корзину без регистрации.
- Зарегистрироваться, подтвердить почту кодом из письма и войти по почте и паролю.
- Оформить заказ с доставкой или самовывозом.
- Смотреть свои заказы, менять имя, телефон и пароль, писать и изменять свои отзывы.
- Восстановить забытый пароль через письмо или удалить свой аккаунт.

Оформление заказа, личный кабинет и написание отзыва требуют входа. Для просмотра каталога вход не нужен.

## Что может владелец

Администратор — человек с правами управления магазином. В админ-панели ему доступны товары, категории, заказы, пользователи, отзывы, фотографии страницы «О нас», обзор продаж и проверка настроек перед запуском.

Права администратора в магазине с сервером задаются настройками сервера. Обычная регистрация таких прав не даёт. Подробная инструкция — в [разделе 11 «Админ-панель»](11-Админ-панель.md).

## Что нужно знать об оплате

В проекте есть перевод на Kaspi с ручным подтверждением владельцем и оплата при получении. Отдельно есть **тестовая оплата** картой и через имитацию Kaspi. Она показывает ход оплаты, но денег не списывает.

Для Kaspi Pay в коде подготовлена отдельная заготовка подключения. Её работу с настоящим платёжным сервисом нужно проверить и при необходимости доработать. Само наличие этого кода ещё не означает, что магазин принимает настоящие онлайн-платежи. Подробнее — [раздел 10 «Оплата»](10-Оплата.md).

## Два режима: для показа и для покупателей

**Режим без сервера** подходит для знакомства с сайтом. Данные сохраняются в браузере конкретного человека. Изменения на одном компьютере не появляются у другого посетителя. Очистка данных браузера может их удалить. В этом режиме нельзя полагаться на вход и роль администратора как на защиту настоящего магазина.

**Режим с сервером** нужен для общего каталога, аккаунтов и заказов. Сервер — постоянно работающая программа, к которой обращается сайт. Он проверяет права, считает сумму заказа и сохраняет данные в общей базе. Локально, то есть на своём компьютере, сервер можно запускать для проверки.

Адрес сервера задаётся в `frontend/env.js`. Пустой адрес включает режим без сервера. При публикации используются настройки выбранного способа размещения.

## Какие части есть в проекте

| Часть | Простыми словами | Где искать |
|---|---|---|
| Фронтенд | Страницы и кнопки, которые видны в браузере | `frontend/` |
| Бэкенд | Программа, которая проверяет вход, товары, заказы и оплату | `backend/` |
| База данных | Общее хранилище записей магазина | SQLite на своём компьютере; PostgreSQL на сервере |
| Публикация | Файлы для размещения магазина в интернете | `deploy/`, `render.yaml` |
| Демо-версия | Отдельная витрина с примерами для показа | `demo/` |
| Тесты | Автоматические проверки отдельных частей проекта | `backend/tests/`, `tests/`, `demo/tests/` |
| Документация | Инструкции для владельца и разработчика | `docs/` |
