# 2. Как запустить на своём компьютере

## Подготовка: как вводить команды

Для запуска нужен **Python 3.11 или новее**. Python — программа, которая выполняет файлы проекта с расширением `.py`. VS Code для запуска не обязателен: команды можно вводить в обычном PowerShell.

На Windows откройте папку проекта в Проводнике. Это папка, внутри которой лежат `frontend`, `backend`, `demo` и `deploy`. Нажмите на строку адреса, напишите `powershell` и нажмите Enter. Откроется окно для команд — **терминал**.

Вставляйте только текст из блоков команд. После каждой команды нажимайте Enter и ждите результат. Не вводите адрес сайта в терминал: адрес нужно открывать в браузере.

Проверьте Python:

```powershell
python --version
```

Ожидаемый результат — строка вида `Python 3.11…` или более новая версия. Если команда не найдена, установите Python и снова откройте PowerShell. Если на вашем компьютере работает команда `py`, вместо `python` в инструкциях можно использовать `py`.

Выберите один из трёх вариантов ниже. Для первого знакомства удобнее вариант 1. Файлы настроек `.env` для обычного локального запуска не нужны, если вы ещё не создавали собственные настройки.

## Вариант 1. Посмотреть готовое демо

Демо — версия с примерами товаров, отзывов и заказов. Она подходит, чтобы понять работу магазина, не настраивая настоящую базу и почту.

В терминале, открытом в папке проекта, выполните:

```powershell
python demo/serve.py
```

Когда появится строка `Демо: http://localhost:5175`, откройте в браузере **http://localhost:5175**. `localhost` означает «этот же компьютер».

На странице входа есть кнопки быстрого входа. Можно также ввести данные вручную:

| Кому войти | Почта | Пароль |
|---|---|---|
| Покупателю | `buyer@demo.kz` | `demo123` |
| Администратору | `admin@demo.kz` | `admin123` |

Эти данные относятся только к демо. Изменения хранятся в браузере. Подробнее о демо — [раздел 15](15-Демо-версия.md).

Оставьте окно PowerShell открытым, пока смотрите сайт. Чтобы остановить демо, вернитесь в это окно и нажмите **Ctrl + C**.

## Вариант 2. Проверить магазин с сервером

Этот вариант проверяет настоящую серверную логику: вход, общие товары, заказы и тестовую оплату. На своём компьютере вместо PostgreSQL используется **SQLite** — база в одном файле `backend/dev.db`.

### Шаг 1. Один раз установить нужные библиотеки

Библиотеки — готовые части программы, от которых зависит сервер. В терминале из папки проекта выполните по очереди:

```powershell
python -m venv backend/.venv
```

```powershell
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
```

Первая команда создаёт отдельную папку с Python для проекта — **виртуальное окружение**. Вторая скачивает и устанавливает библиотеки; для неё нужен интернет. Дождитесь окончания без сообщения об ошибке. Повторять установку нужно, если изменился список библиотек или удалена папка `.venv`.

### Шаг 2. Запустить сервер в первом окне

В том же терминале выполните:

```powershell
cd backend
```

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

При первом запуске создаются база `backend/dev.db`, стартовые категории и локальный администратор. Когда сервер сообщит `Application startup complete`, оставьте окно открытым.

Данные локального администратора: **`admin@demo.kz` / `admin12345`**. Пароль отличается от пароля демо из варианта 1.

Письма локально не отправляются. Когда сайт попросит код подтверждения или сброса пароля, откройте `backend/dev-mail.log` обычным Блокнотом и найдите последнее письмо для нужной почты.

### Шаг 3. Указать сайту адрес сервера

Откройте файл `frontend/env.js` в текстовом редакторе, например в Блокноте. Задайте строку и сохраните файл:

```javascript
window.KBCH_API_URL = 'http://localhost:8000/api';
```

Этот адрес подходит только для проверки на своём компьютере. Перед публикацией нужен адрес вашего сервера или `/api` согласно инструкции размещения. Не отправляйте в репозиторий рабочие настройки с `localhost`.

### Шаг 4. Запустить сайт во втором окне

Откройте **ещё одно** окно PowerShell из папки проекта. В нём должна быть видна папка с `frontend`, `backend` и `deploy`, а не сама папка `backend`.

```powershell
python deploy/serve_frontend.py
```

Откройте **http://localhost:5174**. Вход администратора: **http://localhost:5174/admin/**. Пока сайт работает, оба окна PowerShell должны оставаться открытыми. Остановка каждого — **Ctrl + C** в соответствующем окне.

### Шаг 5. При желании добавить примеры товаров

Новая база содержит категории, но товары нужно добавить. Можно создать свои товары в админ-панели или загрузить примеры. Для примеров откройте третье окно PowerShell из папки проекта:

```powershell
.\backend\.venv\Scripts\python.exe demo/seed_backend.py
```

Команда предназначена для локальной демонстрации. После неё обновите страницу каталога. Не используйте заполнение примерами как обычный шаг запуска магазина с реальными данными.

Локальное описание **API** — адресов, по которым сайт обращается к серверу, — открывается по ссылке **http://localhost:8000/api/docs**.

## Вариант 3. Открыть пустой сайт без сервера

В `frontend/env.js` задайте пустой адрес:

```javascript
window.KBCH_API_URL = '';
```

Из папки проекта запустите:

```powershell
python deploy/serve_frontend.py
```

Откройте **http://localhost:5174**. На чистом хранилище браузера товаров не будет. Чтобы управлять этой версией, впишите свою почту в список `adminEmails` файла `frontend/js/config.js` и зарегистрируйтесь с ней.

Этот режим сохраняет данные только в браузере. Он подходит для показа и подготовки содержимого. Защиту и общие данные настоящего магазина обеспечивает вариант с сервером.

## Если что-то не получилось

- **Открылся код или страница без оформления.** Открывайте сайт по адресу `http://localhost:…`, а не двойным щелчком по HTML-файлу.
- **Сайт пишет, что сервер недоступен.** Проверьте первое окно PowerShell и строку в `frontend/env.js`. У сайта и сервера разные порты: `5174` и `8000`.
- **Администратор не входит.** Для демо пароль `admin123`, для локального сервера — `admin12345`.
- **Адрес не открывается с телефона.** Эти команды запускают просмотр только на компьютере. `localhost` на телефоне означает сам телефон. Обычную опубликованную версию можно открыть на любом устройстве.
- **Правки не появились.** Сохраните файл и обновите страницу. Для локального просмотра используйте `deploy/serve_frontend.py`: он отключает кеширование и показывает свою страницу ошибки 404.

Команды выше предназначены для Windows PowerShell. На macOS и Linux Python окружения находится в `backend/.venv/bin/python`; из папки `backend` — в `.venv/bin/python`.

Для тестовой оплаты используйте только примеры из [раздела 10](10-Оплата.md). Как запускать автоматические проверки, описано в [разделе 16](16-Тесты-и-проверка-качества.md).
