# Тесты проекта

Тест — маленькая программа, которая сама проверяет, что сайт ведёт себя правильно. Полное описание простыми словами — [docs/16-Тесты-и-проверка-качества.md](../docs/16-Тесты-и-проверка-качества.md).

| Папка | Что проверяет |
|---|---|
| `tests/frontend/` | Логика сайта: экранирование, цены, телефон, корзина, избранное, фильтры |
| `tests/general/` | Состав `.public/`, склейка стилей, API URL и пути к картинкам |
| `backend/tests/` | API, заказы, оплата, база данных, безопасность и настройки |
| `demo/tests/` | Изоляция демо, сборка, фото и версия ассетов |

Число проверок зависит от текущей версии проекта. Как подготовиться, запустить проверки и понять их результат — в [главе 16](../docs/16-Тесты-и-проверка-качества.md).

## Как запустить

Логика сайта (из корня проекта, нужен Node.js 20+):
```bash
node --test tests/frontend/*.test.cjs
```
Сборка (из корня проекта):
```bash
python -m pytest
```
Сервер (из папки `backend`):
```bash
.\.venv\Scripts\python.exe -m pytest
```
Демо-версия (из корня проекта):
```bash
python -m pytest demo/tests
```

## Как устроены

- Тесты JS загружают настоящие файлы сайта в изолированную «песочницу» с поддельным хранилищем браузера.
- Тесты сборки работают во временной папке и не трогают настоящую `.public/`.
- Тесты сервера работают на временной SQLite или на отдельной базе из `TEST_DATABASE_URL`, таблицы создаются заново для каждого сценария. Не указывайте рабочую базу: фикстура удаляет таблицы. Письма и платёжные вызовы имитируются.
