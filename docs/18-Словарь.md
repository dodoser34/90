# 18. Словарь простыми словами

Не нужно учить все слова заранее. Найдите здесь термин, который встретился в инструкции, и возвращайтесь к нужному шагу. В Word удобно пользоваться поиском по документу.

## Основы программирования

Примеры кода с этими понятиями — в [главе 19](19-Основы-HTML-CSS-JS-Python.md).

| Слово | Что означает |
|---|---|
| Программа / код | Точная инструкция для компьютера и текст этой инструкции |
| Язык программирования | Набор слов и правил, на котором пишут программы: Python, JavaScript |
| Переменная | Именованная «коробка» для значения, например `price = 5000` |
| Тип данных | Вид значения: число, строка, да/нет, список, объект |
| Строка | Текст в кавычках, например `'Крем'` |
| Массив / список | Упорядоченный набор значений: `[1, 2, 3]` |
| Объект / словарь | Набор пар «имя — значение»: `{ name: 'Крем', price: 5000 }` |
| Условие | Развилка «если — иначе», в коде `if` / `else` |
| Цикл | Повторение действий для каждого элемента или пока верно условие |
| Функция | Именованный набор действий, который вызывают много раз |
| Параметр / аргумент | Значение, которое передают функции на вход |
| Класс | Чертёж, по которому создаются объекты одного вида |
| Событие | То, что случилось на странице: нажатие, ввод, прокрутка |
| Библиотека | Готовый код других разработчиков, который подключают к проекту |
| Синтаксис | Правила записи языка: скобки, кавычки, отступы |
| Ошибка / исключение | Сообщение о том, что программа не смогла выполнить действие |
| Traceback | Отчёт Python об ошибке; читают снизу вверх |
| Отладка | Поиск и исправление ошибок |
| Селектор | Часть правила CSS, которая говорит, к каким элементам оно относится |
| Медиазапрос | Правило CSS, которое работает только при определённой ширине экрана |
| Flexbox / Grid | Способы раскладки блоков в CSS: в линию или сеткой |
| Первичный ключ | Уникальный номер строки в таблице базы данных |
| Внешний ключ | Ссылка из строки одной таблицы на строку другой |
| CRUD | Четыре действия с данными: создать, прочитать, изменить, удалить |
| Ветка | Параллельная версия проекта в Git для отдельной задачи |

| Хостинг | Услуга размещения сайта и его программ в интернете |
| VPS | Арендованный виртуальный сервер, которым можно управлять самостоятельно |

## Части сайта и данные

| Слово | Что означает |
|---|---|
| Фронтенд | Страницы и действия, с которыми посетитель работает в браузере |
| Бэкенд | Серверная программа: проверяет права, принимает заказы, считает суммы и работает с базой |
| HTML | Разметка содержимого: заголовков, текста, ссылок и кнопок |
| CSS | Правила внешнего вида: цветов, размеров, расположения элементов |
| JavaScript / JS | Язык действий и логики в браузере; также используется вне браузера |
| Python | Язык серверной программы и служебных скриптов проекта |
| Фреймворк | Готовая основа для разработки приложения с общими правилами и инструментами |
| FastAPI | Основа серверного приложения этого магазина на Python |
| API | Адреса и правила, по которым сайт запрашивает данные и передаёт действия серверу |
| HTTP | Правила обмена запросами и ответами между браузером и сервером |
| REST | Подход, где адрес обозначает данные, а метод запроса — действие: получить, создать, изменить, удалить |
| JSON | Текстовая запись данных со списками и полями. Используется в API и выгрузке панели |
| JSONB | Способ хранения JSON внутри PostgreSQL |
| База данных | Упорядоченное хранилище товаров, аккаунтов, заказов и других записей |
| PostgreSQL | Система базы данных рабочего магазина |
| SQLite | Более простая база в одном файле, используемая для локальной разработки и части тестов |
| SQL | Язык запросов к базе данных |
| ORM / SQLAlchemy | Средство работы с таблицами из Python без ручного составления каждого SQL-запроса |
| Миграция базы / Alembic | Записанный шаг изменения структуры таблиц, например добавление поля |
| Миграция данных | Преобразование уже сохранённых данных для новой версии программы |
| Транзакция | Связанные изменения, которые сохраняются целиком или отменяются при ошибке |

## Оформление и удобство

| Слово | Что означает |
|---|---|
| Адаптивность | Перестройка страницы под экран телефона, планшета или компьютера |
| Media query | Условие CSS, применяющее оформление при подходящем размере или свойстве экрана |
| `px` / пиксель | Единица размеров интерфейса и изображений; CSS-пиксель не всегда равен одной точке матрицы |
| 2K / 4K | Условные обозначения экранов высокого разрешения; конкретные размеры проверяют отдельно |
| `zoom` | Свойство CSS для изменения масштаба элемента |
| SVG | Изображение из линий и фигур, которое сохраняет чёткость при увеличении |
| JPG / PNG / WEBP | Форматы изображений. PNG и WEBP могут сохранять прозрачность |
| base64 | Способ передать двоичные данные, например картинку, в текстовой записи |
| Заглушка / placeholder | Временный текст или картинка вместо отсутствующего содержимого |
| Карусель | Ряд карточек или изображений с перелистыванием |
| Лайтбокс | Окно просмотра фотографии поверх страницы |
| Toast | Короткое всплывающее сообщение, например «Товар добавлен» |
| Меню «бургер» | Кнопка с тремя полосками, открывающая меню на узком экране |
| Маска CSS | Правило, которое скрывает части изображения или делает их прозрачными |
| View Transitions | Возможность браузера плавно показывать смену страницы или состояния |
| SEO | Настройка сайта и его содержимого для поиска в поисковых системах |
| JSON-LD | Структурированные сведения для поисковых систем, например о цене и наличии |
| Модерация | Проверка опубликованного содержимого: например, скрытие неподходящего отзыва |

## Вход, оплата и защита

| Слово | Что означает |
|---|---|
| Сессия | Запись о входе пользователя, позволяющая не вводить пароль при каждом действии |
| Токен | Случайная строка доступа, которую браузер получает после входа и передаёт с запросами |
| Хеш | Проверочный отпечаток значения. Он не предназначен для восстановления исходного пароля |
| bcrypt | Алгоритм хеширования паролей, замедляющий их перебор |
| Соль | Случайная добавка при хешировании, чтобы одинаковые пароли имели разные хеши |
| HMAC / подпись | Проверочный отпечаток данных с секретным ключом; помогает обнаружить подделку сообщения |
| HTTPS / сертификат | Шифрованное соединение и подтверждение имени сайта. Само по себе не гарантирует честность сайта |
| Let's Encrypt | Сервис выдачи сертификатов, используемый в Docker-схеме проекта |
| CORS | Правила браузера, какие другие адреса могут читать ответы API |
| CSP | Правила, откуда браузер может загружать и выполнять содержимое страницы |
| SQL-инъекция | Попытка превратить введённый текст в команду базе данных |
| XSS | Выполнение чужого скрипта через содержимое сайта |
| CSRF | Попытка заставить браузер выполнить действие от имени вошедшего пользователя через чужой сайт |
| Брутфорс | Перебор множества паролей или кодов |
| DDoS | Распределённая перегрузка сервиса большим количеством обращений |
| Лимит запросов | Ограничение частоты действий; при превышении сервер может ответить ошибкой 429 |
| Webhook | Запрос от внешнего сервиса к магазину, например уведомление о результате платежа |
| Эквайринг | Услуга приёма банковских платежей |
| Sandbox / тестовая оплата | Имитация оплаты без настоящего списания денег |
| Алгоритм Луна | Проверка некоторых ошибок в номере карты; не доказывает, что карта существует или платёж пройдёт |
| Демо-аккаунт | Подготовленный аккаунт для показа и тренировки |
| Демо-наполнение | Примерные товары, отзывы и заказы из `demo/` |

## Сопровождение и разработка

| Слово | Что означает |
|---|---|
| Docker / контейнер | Способ запускать программу в отдельном окружении с нужными компонентами |
| Docker Compose | Настройка и совместный запуск нескольких сервисов, например API и базы |
| Volume / том | Отдельное постоянное хранилище Docker. Удаление контейнера и удаление тома — разные действия |
| Nginx | Веб-сервер, который отдаёт страницы, обслуживает HTTPS и передаёт запросы API |
| Reverse proxy | Промежуточная программа, принимающая запросы и передающая их приложению |
| Middleware | Общая проверка или обработка запроса до либо после основного обработчика |
| ASGI | Правила взаимодействия асинхронного Python-приложения с сервером его запуска |
| Worker | Отдельный процесс, обрабатывающий запросы API |
| Healthcheck | Короткая проверка доступности сервиса; не заменяет проверку всех функций |
| Резервная копия / бэкап | Сохранённые данные для восстановления после потери или ошибки |
| Дамп / `.dump` | Файл копии базы PostgreSQL |
| Архив / `.tgz` | Упакованный набор файлов; в этом проекте так копируются фотографии |
| Откат | Возврат к рабочей версии кода и, при необходимости, к выбранной копии данных |
| Тест / автотест | Программа, проверяющая ожидаемое поведение |
| Фикстура | Подготовка условий теста и очистка после него |
| Mock | Управляемая подмена внешнего действия в тесте, например отправки письма |
| CI / GitHub Actions | Автоматические действия при подходящих изменениях проекта: тесты, сборка, публикация |
| E2E | Проверка полного пути пользователя через несколько частей приложения |
| Зависимость | Сторонний пакет, нужный программе |
| Транзитивная зависимость | Пакет, который нужен одному из установленных пакетов |
| Lock-файл | Зафиксированный набор версий зависимостей для повторяемой установки |
| YAML / INI | Форматы записи настроек; важны отступы, имена полей или секций |
| Idempotency / идемпотентность | Повтор одного действия не создаёт повторного результата, например второго подтверждения того же платежа |

Примеры кода — [глава 19](19-Основы-HTML-CSS-JS-Python.md). Назначение файлов настроек — [глава 21](21-Конфигурационные-файлы.md).
