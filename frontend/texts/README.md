# Тексты сайта

Здесь лежат **все тексты сайта**: заголовки, кнопки, подсказки, сообщения об ошибках, вопросы-ответы, подписи к фото.
Тексты о товарах (названия, описания, состав) и категории сюда не входят — их меняют в админ-панели.

## Где какой текст

Папка `ru/` — русский язык. Один файл — один раздел сайта:

| Файл | Что внутри |
|---|---|
| `common.js` | То, что есть на всех страницах: шапка, мобильное меню, подвал, три преимущества, карточка товара, уведомления «Добавлено в корзину», окна «Вы уверены?», статусы заказов, сообщения об ошибках |
| `home.js` | Главная: первый экран, заголовки подборок, круги-категории |
| `catalog.js` | Каталог: заголовки, фильтры, сортировка, «Ничего не найдено» |
| `product.js` | Страница товара: покупка, вкладки, отзывы, форма «Оставить отзыв» |
| `about.js` | О нас: миссия, цифры, «Почему нам доверяют», подписи к фото, контакты |
| `delivery.js` | Доставка и оплата: способы, таблица сроков, частые вопросы |
| `cart.js` | Корзина |
| `checkout.js` | Оформление заказа и экран «Спасибо за заказ» |
| `pay.js` | Страница тестовой оплаты картой и через Kaspi |
| `favorites.js` | Избранное |
| `login.js` | Вход и регистрация |
| `account.js` | Личный кабинет |
| `not-found.js` | Страница «Страница не найдена» (404) |

## Как править

Тексты меняются **только в этих файлах** — в админ-панели правки текстов нет (так никто не испортит сайт случайно).

### Правка файлов

Откройте нужный файл в текстовом редакторе, например в Блокноте, и меняйте **только текст между кавычками**. Word подходит для чтения руководства, но файлы `.js` в нём редактировать не следует:

```js
title: 'Корзина',
```

Например, «Корзина» можно заменить на «Ваша корзина». Правила:

- Кавычки `'…'`, двоеточия, запятые и скобки не трогайте.
- Если в тексте нужен апостроф, поставьте перед ним обратную косую черту: `'Л\'Окситан'`.
- `<br>` — перенос строки, `<b>…</b>` — жирный текст.
- `{count}`, `{name}`, `{sum}` и другие слова в фигурных скобках — сюда сайт сам подставит число, имя или сумму. Их можно переставить внутри фразы, но не переименовывать.
- `{count|товар|товара|товаров}` — слово в нужной форме для числа: 1 товар, 2 товара, 5 товаров.
- `meta.title` — заголовок вкладки браузера, `meta.description` — описание страницы для поисковиков. `{shop}` — название магазина из `js/config.js`.
- Списки в квадратных скобках (`[ … ]`) можно дополнять: например, добавить вопрос в `delivery.js → faq` или строку в таблицу сроков.

После правки сохраните файл и обновите страницу. При публикации поднимите номер версии (см. [docs/12](../../docs/12-Тексты-фото-и-частые-правки.md)), чтобы посетители сразу увидели новые тексты.

Если текст на сайте вдруг показался в виде `catalog.empty.title` — значит, в файле удалили или переименовали этот ключ; в консоли браузера (F12) будет подсказка, какой именно.

## Как добавить другой язык

1. Скопируйте папку `ru` и назовите копию кодом языка, например `kk` (казахский) или `en`.
2. Переведите тексты в копии.
3. В HTML-страницах (`index.html`, `404.html`, `pages/*.html`) поменяйте `<html lang="ru">` на `<html lang="kk">` — сайт возьмёт тексты из папки `texts/kk/`.

Для переключателя языков на самом сайте нужно будет добавить кнопку, которая меняет язык, — тексты к этому уже готовы.
