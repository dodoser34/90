# Фронтенд магазина

HTML, CSS и JavaScript магазина и админки — без сборки и фреймворков. Простыми словами:
[HTML](../docs/04-Фронтенд-HTML-страницы.md), [CSS и адаптивность](../docs/05-Фронтенд-CSS-оформление-и-адаптивность.md), [JavaScript](../docs/06-Фронтенд-JavaScript.md).

Запуск из корня проекта:
```bash
python deploy/serve_frontend.py
```
Откройте http://localhost:5174. Чтобы сайт работал с локальным сервером, в `env.js` укажите:
```javascript
window.KBCH_API_URL = 'http://localhost:8000/api';
```
При пустом адресе данные хранятся в браузере (удобно для правки дизайна).

## Что где

| Путь | Что внутри |
|---|---|
| `index.html`, `404.html`, `pages/` | страницы магазина |
| `admin/` | админ-панель |
| `texts/ru/` | все тексты сайта ([как править](texts/README.md)) |
| `assets/` | картинки оформления и фото сайта |
| `css/` | стили: основа, компоненты, страницы, адаптивность, админка |
| `js/app.js` | загрузчик: подключает нужные скрипты для каждой страницы |
| `js/core/` | тексты, форматирование, вход, запуск |
| `js/store/` | данные: товары, корзина, избранное; `remote.js` — связь с сервером |
| `js/pages/`, `js/components/`, `js/admin/` | поведение страниц, общих блоков и админки |

Демо-товаров здесь нет — демо-версия лежит отдельно в [`../demo/`](../demo/README.md).
Сборка для публикации: `python deploy/prepare_frontend.py` — кладёт только публичные файлы в `.public/` и склеивает стили в один файл.
