# 18. Словарь терминов

| Термин | Простыми словами |
|---|---|
| **Фронтенд** | Всё, что видит и трогает посетитель: страницы, кнопки, анимации. Работает в браузере |
| **Бэкенд** | «Кухня» сайта на сервере: база данных, приём заказов, оплата. Посетитель её не видит |
| **HTML** | Язык разметки: каркас страницы (заголовки, абзацы, кнопки) |
| **CSS** | Язык оформления: цвета, шрифты, отступы, раскладка |
| **JavaScript (JS)** | Язык программирования в браузере: делает сайт интерактивным |
| **Фреймворк** | Готовый «каркас» для программиста (React, Vue и т.п.). На фронтенде фреймворка нет, на сервере используется FastAPI |
| **Браузер** | Программа для открытия сайтов: Chrome, Safari, Edge, Firefox |
| **localStorage** | «Ящик» в браузере, где сайт хранит данные. У каждого браузера свой |
| **Сервер** | Компьютер в интернете, который отдаёт сайт и хранит общие данные |
| **Хостинг** | Аренда места на сервере, чтобы сайт был доступен всем |
| **Домен** | Адрес сайта, например `kbeauty-chealth.kz` |
| **API** | «Окошко выдачи» на сервере: сайт отправляет запрос («дай товары») и получает ответ |
| **База данных** | Упорядоченное хранилище записей: товаров, заказов, пользователей |
| **Админка** | Закрытая часть сайта для управления магазином |
| **Сессия** | Отметка «пользователь вошёл», чтобы не вводить пароль на каждой странице |
| **Хеш пароля** | Односторонний «отпечаток» пароля, а не шифрование: по нему можно проверить пароль, но нельзя его прочитать |
| **slug** | Часть адреса страницы латиницей, например `anua-heartleaf-77-soothing-toner` |
| **Адаптивность** | Умение сайта подстраиваться под размер экрана |
| **Media query** | Правило CSS «если экран такой-то ширины — оформи так» |
| **px (пиксель)** | Точка на экране, единица размера |
| **2K / 4K** | Мониторы высокого разрешения: 2560 и 3840 точек в ширину |
| **zoom** | Свойство CSS, которое пропорционально увеличивает интерфейс |
| **SVG** | Формат картинок из линий, который не теряет чёткость при увеличении (логотип, иконки) |
| **JPG / PNG** | Форматы фото. PNG поддерживает прозрачный фон |
| **base64** | Способ записать картинку текстом. Так фото из админки передаются на сервер |
| **JSON** | Текстовый формат данных. В нём делается экспорт и импорт в админке |
| **JSON-LD** | Скрытая разметка для поисковиков: цена, рейтинг, наличие |
| **SEO** | Работа над тем, чтобы сайт находился в Google и Яндексе |
| **Заглушка (placeholder)** | Временная картинка вместо отсутствующего фото |
| **Карусель** | Лента карточек, которая листается стрелками или пальцем |
| **Лайтбокс** | Просмотр фото на весь экран поверх страницы |
| **Toast (уведомление)** | Всплывающее сообщение в углу экрана, например «Добавлено в корзину» |
| **Бургер (≡)** | Кнопка из трёх полосок, открывающая меню на телефоне |
| **Промпт** | Текстовое задание для нейросети |
| **Локальный сервер** | «Домашний сервер» на своём компьютере для проверки сайта. Адрес `http://localhost:…` |
| **Демо-аккаунт** | Готовый тестовый аккаунт: вход в один клик, без регистрации |
| **Загрузчик (`app.js`)** | Файл, который подключает все остальные файлы сайта в нужном порядке |
| **assets** | «Ресурсы»: папка с картинками сайта (`assets/images/`) |
| **Миграция данных** | Автоматическое обновление сохранённых данных под новую версию сайта |
| **Алгоритм Луна** | Простая проверка номера карты на опечатки. Используется в тестовой оплате картой, как в настоящих платёжных формах |
| **Модерация** | Проверка отзывов администратором: ответить, скрыть или удалить |
| **Кеш браузера** | Копии файлов сайта, которые браузер хранит, чтобы не скачивать заново. Поэтому после правок нужен `Ctrl + F5` |
| **Маска (CSS)** | Способ сделать края картинки плавно прозрачными |
| **View Transitions** | Встроенная в браузер технология плавных переходов между страницами и состояниями страницы |
| **Демо-наполнение** | Примерные товары, отзывы и аккаунты для показа сайта. Лежат в `demo/` и удаляются вместе с папкой |
| **Prettier** | Программа, которая автоматически выравнивает оформление кода |
| **FastAPI** | Библиотека на Python, на которой написан сервер магазина |
| **PostgreSQL** | Программа базы данных, в которой хранятся товары, заказы и пользователи |
| **SQL** | Язык запросов к базе данных |
| **ORM (SQLAlchemy)** | Способ работать с базой из кода на Python, не составляя SQL-текст вручную |
| **Миграция базы (Alembic)** | Записанное изменение структуры базы (новая таблица, поле), которое сервер применяет сам |
| **REST** | Правило построения API: адрес — что (товары), метод — что сделать (GET получить, POST создать, DELETE удалить) |
| **bcrypt** | Алгоритм хеширования паролей: медленный и с солью, чтобы замедлить подбор пароля |
| **Соль** | Случайная добавка к паролю перед хешированием: одинаковые пароли дают разные хеши |
| **Токен** | Длинная случайная строка-«пропуск», которую сервер выдаёт после входа |
| **HMAC / подпись** | Отпечаток данных, сделанный секретным ключом: по нему видно, что данные не подделаны |
| **Webhook** | Уведомление, которое внешний сервис (Kaspi) сам присылает на сервер, например «заказ оплачен» |
| **.env** | Файл с настройками и паролями сервера. Хранится только на сервере, не попадает в git |
| **Docker / контейнер** | Способ упаковать программу со всем нужным, чтобы она одинаково запускалась на любом сервере |
| **Nginx** | Веб-сервер: принимает посетителей, отдаёт страницы, включает HTTPS, передаёт запросы в API |
| **HTTPS / SSL-сертификат** | Шифрованное соединение (замок в адресной строке). Сертификат выдаёт Let's Encrypt бесплатно |
| **VPS** | Арендованный виртуальный сервер в интернете |
| **SQL-инъекция** | Атака: в поле формы вводят кусок SQL-команды, чтобы управлять базой. Здесь применяются параметризованные запросы и проверка данных |
| **XSS** | Атака: на страницу подкидывают чужой скрипт через текст или ссылку. Здесь применяются экранирование, ограничения URL и CSP |
| **CSRF** | Атака: чужой сайт отправляет запрос от имени вошедшего пользователя. В проекте Bearer-токен вместо cookie уменьшает классический риск такой атаки |
| **DDoS / брутфорс** | Перегрузка сайта массой запросов / подбор пароля перебором. Защита — ограничение числа запросов |
| **CSP** | Правило для браузера, откуда можно загружать скрипты. Защищает от XSS |
| **Резервная копия (бэкап)** | Копия базы данных, из которой её можно восстановить |
| **Тест (автотест)** | Программа, которая сама проверяет, что функция сайта работает правильно |
| **CI (GitHub Actions)** | Автоматический запуск тестов в GitHub при изменениях, соответствующих условиям workflows |
| **Тестовая оплата (песочница)** | Имитация онлайн-оплаты: весь путь как настоящий, но деньги не списываются |
| **Эквайринг** | Услуга банка по приёму оплаты картами на сайте |
| **Склейка стилей (бандл)** | Объединение многих CSS-файлов в один при публикации, чтобы страница грузилась быстрее |
| **CORS** | Правило, с каких сайтов браузеру разрешено обращаться к API магазина |
| **Middleware** | «Пропускной пункт» на сервере: проверяет каждый запрос до основной обработки (размер, частота, заголовки) |
| **Контейнер (Docker)** | Упакованная программа со всем нужным для работы; одинаково запускается на любом сервере |

## Термины разработки и конфигурации

| Термин | Простыми словами |
|---|---|
| **Python** | Язык серверного приложения и служебных скриптов проекта |
| **DOM** | Дерево элементов страницы, с которым работает JavaScript |
| **HTTP** | Протокол запросов и ответов между браузером и сервером |
| **Origin** | Схема, домен и порт; важно для CORS и localStorage |
| **ASGI** | Интерфейс асинхронного Python-приложения и веб-сервера |
| **JSONB** | Представление JSON в PostgreSQL |
| **Транзакция** | Группа изменений базы, которую сохраняют целиком либо откатывают |
| **Фикстура** | Подготовка и очистка окружения теста |
| **Mock** | Подмена внешнего действия контролируемым ответом в тесте |
| **EditorConfig** | Общие настройки кодировки, отступов и переводов строк |
| **Gitignore** | Исключения неотслеживаемых файлов из добавления в Git |
| **Dockerignore** | Исключения файлов из контекста сборки Docker |
| **YAML / INI** | Форматы конфигурации с отступами / секциями |
| **Зависимость** | Пакет, нужный программе для работы |
| **Транзитивная зависимость** | Пакет, нужный другой подключённой библиотеке |
| **Lock-файл** | Закреплённый набор разрешённых версий зависимостей |
| **Deploy** | Размещение и запуск приложения |
| **Volume** | Постоянное хранилище вне изменяемого слоя контейнера |
| **Healthcheck** | Проверка доступности сервиса, не всех его функций |
| **Worker** | Отдельный процесс обработки запросов API |
| **Reverse proxy** | Промежуточный сервер, пересылающий запросы приложению |
| **Idempotency** | Повтор действия без повторного эффекта |
