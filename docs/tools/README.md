# Как обновить Word и версию для браузера

Этот раздел нужен только тому, кто меняет документацию. Для обычного чтения откройте готовый Word или HTML в папке docs.

Текст хранится в файлах `docs/00-Оглавление.md` и `docs/01-...md` — `docs/27-...md`. В конец добавляются требования к фотографиям. Сначала измените нужную главу, затем заново соберите оба файла для чтения.

Из корня проекта выполните в PowerShell:

```powershell
python -m pip install python-docx
python docs/tools/build_guide.py
```

Первая команда устанавливает библиотеку для создания Word; её достаточно выполнить один раз в выбранном окружении Python. Вторая создаёт заново `docs/Руководство по магазину.docx` и `docs/Читать-в-браузере.html`. Закройте Word перед пересборкой, если он держит файл открытым.

Сборщик переносит заголовки, ссылки на главы, таблицы, списки и примеры команд. Широкие таблицы в Word превращаются в последовательные записи, чтобы их было легче читать на небольшом экране. В браузере таблицы становятся вертикальными карточками при узком окне.

После сборки откройте Word и проверьте страницы, таблицы, переносы команд и переходы по оглавлению. Затем откройте HTML в браузере и проверьте обычное и узкое окно. Создание файлов само по себе не проверяет их внешний вид. Не вносите основные правки только в Word: при следующей сборке они будут заменены текстом из глав.
